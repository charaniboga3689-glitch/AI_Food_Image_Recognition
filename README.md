# AI-Based Food Image Recognition System

A B.Tech-friendly deep learning project. Users upload a food photo and the website predicts the food category using a CNN-style transfer-learning classifier built on MobileNetV2.

## Main features
- Food image upload (JPG, JPEG, PNG, WEBP)
- Image preview and prediction result
- Top prediction with confidence percentage
- Two alternative predictions
- Responsive Flask website with professional dashboard
- Dashboard statistics, local prediction history, and top recognized foods
- About Project page with two team-member placeholders
- Food-101 dataset with 101 food categories

## Technology stack
- Python
- TensorFlow / Keras
- MobileNetV2 (ImageNet transfer learning)
- TensorFlow Datasets (Food-101)
- Flask
- HTML, CSS, JavaScript

## Setup (Windows)

### 1. Install Python
Use Python 3.10 or 3.11 (recommended for TensorFlow compatibility). During installation, enable **Add Python to PATH**.

### 2. Open the project folder in VS Code
Open Terminal in VS Code and run:

```bash
python -m venv venv
venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### 3. Train the model
Run:

```bash
python train.py
```

The first run downloads the Food-101 dataset through TensorFlow Datasets. This dataset is large and training can take a long time. A GPU is recommended, but CPU training is possible. The script saves:
- `model/food_model.keras`
- `model/class_names.json`

For a quick development test, you can temporarily reduce `EPOCHS_HEAD` and `EPOCHS_FINE` in `train.py`. Accuracy will be lower with fewer epochs.

### 4. Start the website
After training completes, run:

```bash
python app.py
```

Open this address in your browser:

`http://127.0.0.1:5000`

Upload a food image and click **Recognize Food**.

## How it works
1. User uploads a food image.
2. Flask validates and stores the image.
3. Pillow converts it to RGB and resizes it to 224 × 224.
4. MobileNetV2 extracts visual features.
5. The trained classification layer predicts one of the 101 Food-101 categories.
6. The website displays the highest-scoring category and confidence.

## Dataset
Food-101 is provided by TensorFlow Datasets: https://www.tensorflow.org/datasets/catalog/food101

It contains 101 food categories and 101,000 images. The dataset is used for academic experimentation. Follow its original terms and citation requirements if you redistribute dataset images or publish results.

## Important notes
- The ZIP includes the complete source code, not the trained neural-network weights. The model weights are generated by running `python train.py`; they are not included because the dataset/model files are large.
- The confidence percentage is the model's softmax score, not a guarantee that the prediction is correct.
- This is an educational prototype, not a nutrition or allergy safety tool.
- For best results, use a clear photo containing one main food item.
- Uploaded photos are stored locally in `static/uploads/`. Delete that folder's contents when you want to clear saved uploads.

## Troubleshooting
- **No module named tensorflow:** activate the virtual environment and run `pip install -r requirements.txt`.
- **Model is not installed yet:** run `python train.py` and wait until it completes.
- **Port 5000 is busy:** change the last line in `app.py` to `app.run(debug=True, port=5001)` and open `http://127.0.0.1:5001`.
- **Training is slow:** use a GPU-enabled TensorFlow setup or reduce the dataset/epochs for a demonstration. A reduced run is not equivalent to full Food-101 training.
