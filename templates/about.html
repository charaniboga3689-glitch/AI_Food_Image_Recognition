About the Project

A deep learning application for recognizing food images.

Project overview

FoodVision AI uses transfer learning with MobileNetV2 to classify food images into one of 101 categories from the Food-101 dataset. A Flask web application allows users to upload an image and view the predicted food label, confidence score, and alternative predictions.
